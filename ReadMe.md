# Score Keeper

## Features

### *Interactive Score Tracking Game*

A fun and engaging web application for tracking scores between two players in a competitive game. The application allows you to:

* Track scores for two players (Dr. Jekyll and Mr. Hyde themed)

* Set winning condition at 10 points

* Real-time score display with large, clear numbers

* Automatic winner detection and announcement

* Game state management (buttons hide when game ends)

* Dynamic Game Management: Seamlessly add points, detect winners, and reset games.

* Pure JavaScript: Built with vanilla JavaScript for optimal performance and no dependencies.

* Responsive Design: Eye-catching retro gaming interface with neon colors and effects.

* User-Friendly Interface: Intuitive controls with hover effects, glowing buttons, and visual feedback.

## Technologies Used

This project is built using fundamental web technologies:

* HTML5: Semantic structure for the game interface with clear player sections and scoring buttons.

* CSS3 (with SCSS): Modern styling with gradients, box-shadows, neon effects, and responsive design patterns compiled from SASS.

* JavaScript (ES6+): Event handling, DOM manipulation, game logic, and state management using modern JavaScript features.

## How to Use

* Start Playing: Click either "Dr. Jekyll" or "Mr. Hyde" button to add a point to that player's score.

* Score Tracking: Watch the live score display (format: Player1 - Player2) update in real-time.

* Win Condition: First player to reach 10 points wins the game automatically.

* Winner Announcement: When a player wins, a victory message appears and scoring buttons are hidden.

* Reset Game: Click "Start Again" button to reset scores to 0-0 and begin a new round.

* Visual Feedback: Buttons glow and scale on hover, creating an engaging gaming experience.

## Future Enhancements

* Customizable Max Score: Allow players to set different winning conditions (5, 15, 21 points, etc.).

* Player Names: Enable custom player names instead of fixed Dr. Jekyll/Mr. Hyde theme.

* Score History: Track and display previous game results and statistics.

* Tournament Mode: Support for best-of-series matches with round tracking.

* Keyboard Support: Enable spacebar or arrow key controls for faster gameplay.

* Animation Effects: Add score increment animations and winner celebration effects.
